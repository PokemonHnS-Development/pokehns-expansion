# Voltorb Flip (Goldenrod Game Corner table, bg event (16,6), read from (16,7) facing up):

press UP

tap A 0
talk vf_notes 20 -

press DOWN
press DOWN

# memo mode: R steps through the 1, 2, 3 and Voltorb pencils
press Rb

press Rb
