# Pokeblock case and feeding (src/pokeblock.c, src/use_pokeblock.c, src/pokeblock_feed.c).
# The case is filled in RAM (pokeblocks: gSaveBlock1Ptr->pokeblocks) with one block of every colour,
# RED .. GOLD (PBLOCK_CLR_*, include/pokeblock.h:8-22), so the list shows every name next to its
# {SKIP 0x57} level column (gPokeblockNames, src/pokeblock.c:204-218; list rows :750-761).
# Party slot 0 becomes a level-50 ADAMANT Bronzong (likes spicy, dislikes dry) with a 12-character
# nickname (nick12, the widest STR_VAR_1 for the feeding lines). Then four blocks are fed from the top of
# the list: RED spicy 30 ('happily ate', coolness rose), BLUE dry 30 ('disdainfully ate', beauty rose),
# PINK sweet 30 ('ate', cuteness rose), GREEN bitter 30 (smartness rose); YELLOW has no flavour
# ('nothing changed'); then the sheen is set to 255 (monsheen) and the next block is refused
# ('won't eat any more', PrintWontEatAnymore, src/use_pokeblock.c:959-964). The list is opened on
# row 0 (the saved list position is zero after boot) and every feed returns to row 0; the rest of the
# list is scrolled at the end.
# Run: scripts/r16_contests/con16.py tour ROM OUT --tours tools/hebrew/emu/tours/r16_contests [--clip]
