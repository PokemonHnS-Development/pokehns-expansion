# Round 20 names in script menus (run with scripts/r1_npc_services/svc.py tour): Kurt's ball list
# (MULTI_KURT_BALLS: LOVE and MOON rows name the Psychic and Ghost types), the Game Corner TM prize list
# (MULTI_GAME_CORNER_TMS: TM29), and the Battle Frontier move tutor lists 1 and 2 (SOFT-BOILED,
# COUNTER, SWIFT). No H&S script calls MULTI_KURT_BALLS (Kurt runs special CreateKurtBallShop) and the
# TM prize list is the Mauville Game Corner's; both are drawn here by a RAM script as stand-ins, the
# tutor lists the way m03_scroll draws them. Save: r2menus_postgame.sav.
start saves/r2menus_postgame.sav
include ../../scripts/continue.txt
ev setvar VAR_HAS_ENTERED_BATTLE_FRONTIER, 1; end

# Kurt's ball list
warptoloose MAP_AZALEA_TOWN_KURTS_HOUSE_HNS 4 8

seek 8 @menu:sMenu+2@ 4 DOWN
