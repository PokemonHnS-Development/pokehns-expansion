# Battle Tower lobby, the feelings man at (23,5) (BattleFrontier_BattleTowerLobby_hns/scripts.inc):
# MULTI_BATTLE_TOWER_FEELINGS (every row), then the Easy Chat BATTLE_START, BATTLE_WON and
# BATTLE_LOST screens (2x3 frame, 6 words). The cursor moves by slot and button (ecslot, ecbutton),
# so on every build the same slot is shot under the same name, whichever key reaches it.
# BATTLE_START: the cursor on all six slots and the three buttons, six long words, the cursor on
# three filled slots, START -> "your feeling at the battle's start / is as shown" -> YES -> the
# man's reply. BATTLE_WON and BATTLE_LOST: one word, START -> the YES/NO box over the frame ->
# NO -> back, B -> the quit prompt -> YES. Then "won't tell".
