# Route 34 Day Care (Route34_DayCare_hns/scripts.inc): the four bookshelves with their pages and the
# HELP_DAYCARE1..4 hint windows (src/data/help_window.h), the Odd Egg clerk with a full party (the
# refusal), then with room the question pages and the Easy Chat INTERVIEW screen (2x2 frame). In it:
#  - the cursor on every slot and footer button, moved by slot and button (ecslot, ecbutton), so the
#    same slot has the same shot name on every build;
#  - the group keyboard (post-game: every group) scrolled to its end, the cursor on a first-column and
#    a second-column group, the button window beside the first column (ecdir: the key that leads
#    there differs between a mirrored and an unmirrored build);
#  - the alphabet keyboard: the cursor on every key (eckeys) and every key's word list paged to its
#    end (ecabclists), so the longest list is shown whichever letters the keys carry;
#  - the STATUS (abilities, types), VOICES, FEELINGS and ACTIONS lists paged to their ends;
#  - a wrong answer in all four slots, DEL ALL -> prompt -> NO, B -> quit prompt -> NO, OK ->
#    "the answer is as shown" -> YES -> the clerk's rejection.
# The right answers are ec_oddegg_all.txt. heapstat walks the heap while the screen is open.
