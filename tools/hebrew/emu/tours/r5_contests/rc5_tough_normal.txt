# Party slot 0 becomes a level-50 MACHAMP made by this ROM (so its nickname is the ROM's species name)
# with the moves below; the appeals are the digit string 10233 (the move-list index for each round):
#   0 BODY_SLAM (TOUGH, CONTEST_EFFECT_BADLY_STARTLE_FRONT_MON, src/data/moves_info.h)
#   1 IRON_DEFENSE (TOUGH, CONTEST_EFFECT_AVOID_STARTLE, src/data/moves_info.h)
#   2 TORMENT (TOUGH, CONTEST_EFFECT_MAKE_FOLLOWING_MONS_NERVOUS, src/data/moves_info.h)
#   3 ENDEAVOR (TOUGH, CONTEST_EFFECT_BETTER_IF_LAST, src/data/moves_info.h)
# Iron Defense (avoid startle), Body Slam (badly startle the one before), Torment (nervous), Endeavor twice (better if last; repeated).
# Round 1 points are set to 600 once the contest screen starts (gContestMonRound1Points[3], the
# player is contestant 3), so the player wins and gets the ribbon (contest_hall.inc ReceiveContestRibbon).
# gRngValue is pinned from the lobby on (pinrng), so the opponents, the AI's appeals and the
# audience are the same on the Hebrew and the English ROM (the shots pair up by name).
