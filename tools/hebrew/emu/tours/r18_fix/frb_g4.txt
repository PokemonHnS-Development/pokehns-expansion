# The status tag on the lead's healthbox: frostbite with the Gen 4 battle UI, drawn from
# graphics/battle_interface/gen4/status.png row 5.
# OPTIONS > BATTLE newBattleUI=1 (src/battle_gfx_sfx_util.c UseGen4BattleUI); the status is set with the
# event script's setstatus1 (src/script_pokemon_util.c Script_SetStatus1), as the debug menus do.
# Save: ladder1_newgame.sav (HNS_SAVES). Run with scripts/r4_battle_options/r4opt.py tour (opt).
start saves/ladder1_newgame.sav

pinrng
ev setwildbattle SPECIES_RATTATA, 3; end

waitbattle
bwalk frb_g4_intro input:HandleInputChooseAction
snap frb_g4_healthbox
baction RUN
bwalk frb_g4_run free
