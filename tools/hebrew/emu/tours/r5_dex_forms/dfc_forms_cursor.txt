# Pokedex FORMS page cursor at every position, national numerical list (src/pokedex_plus_hgss.c
# Task_HandleFormsScreenInput :7490-7594, PrintForms :7600-7645): Pikachu (15 forms), Unown (27) and
# Arceus (17), whose positions 14+ have no icon (PrintForms draws 13) and put the arrow on empty rows;
# Castform (3), Paldean Tauros (2), and Alolan Sandslash (no forms: sText_FORMS_NONE). Each list: the
# page out of the cursor (sText_FORMS_Buttons_PE), A (sText_FORMS_Buttons_Submenu_PE) and RIGHT to
# the last form, UP to row 1 and DOWN to the last row on lists of 7 or more, B out of the cursor.
# Then A on Pikachu forms 9-11 (the Sinnoh, Unova and Kalos caps) for their INFO pages.
# The list opens on sLastSelectedPokemon (:2107), so each species is set there before the Pokedex
# opens; SaveBlock2.pokedex (+0x18) mode 1 = national, order 0 = numerical. Leaving the Pokedex
# returns to the field with the start menu open, so the next species is picked from it directly.
# The arrow position depends only on the cursor index, so a fixed waitquiet after each step is enough.
start saves/r2dex_all.sav
include ../../scripts/continue.txt
w8 @SB2+19@ 1
w8 @SB2+18@ 0
