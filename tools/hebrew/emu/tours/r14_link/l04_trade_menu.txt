# The link trade screen (src/trade.c CB2_StartCreateTradeMenu / CB2_CreateTradeMenu / CB2_TradeMenu) on one
# emulator. The partner is faked in RAM the way a cable link leaves it:
#   gReceivedRemoteLinkPlayers = 1 (CB2_CreateTradeMenu state 1 then skips the link-up and goes to state 4),
#   gLinkPlayers[1] = the partner (name, gender), GetMultiplayerId() is 0 without SIO, so the player is the
#   leader and Leader_HandleCommunication runs locally;
#   at state 4..6 the link block exchange (BufferTradeParties) is skipped: the partner's party is written
#   into gEnemyParty and gMain.state set to 7 (the state after the exchange).
# The partner's answers are the statuses a received block would set (Leader_ReadLinkBuffer,
# src/trade.c:1196-1236): sTradeMenu+0x78 playerSelectStatus, +0x79 partnerSelectStatus,
# +0x7A playerConfirmStatus, +0x7B partnerConfirmStatus, +0x7E partnerCursorPosition (6..11);
# STATUS_READY 1, STATUS_CANCEL 2. Offsets from the struct at src/trade.c:179-213 (filler_6A, neverRead_70 and
# filler_7C mark 0x6A / 0x70 / 0x7C).
