# Fight menu, the hard cases of scripts/fight_moves.py (which shows every move): the seven
# names that need the narrower fallback font in Hebrew (wider than the 64-px slot in
# FONT_NARROW; src/battle_message.c:3986-3994), the widest FONT_NARROW name, and names and
# descriptions with Latin letters, parentheses or an ellipsis. Per group of four moves: the
# fight menu with the cursor on each slot (PP / type / effectiveness of that move) and the
# START move-info window of slot 0. The moves are written into gBattleMons[0].moves (u16 x4 at
# +0x0C) and .pp (u8 x4 at +0x25) before FIGHT (src/battle_main.c:4451-4471).

w8 @gBattleMons+26@ 0A
w8 @gBattleMons+27@ 14
w8 @gBattleMons+28@ 0A
