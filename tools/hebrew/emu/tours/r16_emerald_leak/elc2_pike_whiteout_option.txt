# (c, option) As elc_pike_whiteout, with the New Game MODE option SURVIVE POISON turned off
# (poisonsurvive 0; ON by default, src/new_game.c), so the poison can faint the party.
# A field-poison white-out inside a Battle Pike challenge: TryFieldPoisonWhiteOut returns
# FLDPSN_FRONTIER_WHITEOUT in the H&S three-path room (InBattlePike, src/battle_pike.c), so
# EventScript_FrontierFieldWhiteOut runs BattleFrontier_BattlePike_EventScript_Retire
# (data/scripts/field_poison.inc, data/scripts/battle_pike.inc), which warps to the Emerald
# MAP_BATTLE_FRONTIER_BATTLE_PIKE_LOBBY. The challenge is entered at the H&S lobby with real keys
# (CHALLENGE, LV. 50, three Pokemon, save); in the three-path room the option is turned off and the
# party set to poisoned at 1 HP (the only RAM changes), and the player walks until the poison faints it.
start saves/ladder6_postgame.sav

tap A 4
drive elc2_lv menu
