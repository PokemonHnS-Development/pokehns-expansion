# Hebrew nicknames through the Name Rater (Goldenrod), then the party menu and the summary.
#   Typhlosion -> ג'ימי  (gimel, geresh, yod, mem, yod: a geresh between two Hebrew letters)
#   Pikachu    -> פיקה 2 (Hebrew, a space, then a digit from the symbols page)
#   Ampharos   -> ABC   (Latin capitals only)
# Keys on the Hebrew page (visual columns, 0 = left):
#   row 0: . ז ו ה ד ג ב א    row 1: , נ מ ל כ י ט ח
#   row 2: - ש ר ק צ פ ע ס    row 3: ' _ ץ ף ן ם ך ת   (_ = space, ' = geresh)
# The cursor starts on alef (column 7, row 0). A page swap between the Hebrew page and a Latin page
# mirrors the cursor's column (Hebrew column c <-> Latin column 7-c); Latin <-> symbols keeps it.
# The naming screen reads input in sNamingScreen->state == 2 (u8 at +0x1E10).
start save:menuA_base
include ../scripts/continue.txt
