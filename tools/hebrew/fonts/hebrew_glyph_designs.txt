# Hebrew glyph designs for the nine Heart & Soul Latin fonts (install_hebrew_glyphs.py).
#
# Foreground pixels only: '#' = palette index 1, '.' = nothing. Each @glyph block is rows 2..14
# of the 16x16 cell (13 lines); the number after a row is just its cell row. Ink starts at
# column 0. The installer adds the shadow (right, below, below-right of each '#'), the advance
# (last '#' column + 2) and the white box, so only the strokes are drawn here.
#
# Sets (which font uses which: FONTS in install_hebrew_glyphs.py):
#   W6_7    6-column letters, body rows 4-10 (baseline 10)      short
#   W6_8    6-column letters, body rows 4-11 (baseline 11)      normal
#   W5_7    5-column letters, body rows 4-10                    small
#   W5_7SN  W5_7 with the finals' descenders shortened to fit
#           small_narrow's 12-row blit                          small_narrow
#   W5_8    5-column letters, body rows 4-11                    narrow
#   W4_7    4-column letters, body rows 4-10                    small_narrower
#   W4_8    4-column letters, body rows 4-11                    narrower
#   W5_7S / W4_7S  W5_7 / W4_7 with lamed's ascender on rows 2-3   short_narrow / short_narrower
#   LV_*    the level glyph רמה (CHAR_LV 0x34 and CHAR_LV_2 0x105), B10/B11 = baseline row
#
# Origin: W6 = pokefirered-heb latin_normal.png 0x01-0x1B and W5 = its latin_small.png, with the
# ink moved to column 0; the 8-row sets add one body row; the W4 sets are drawn by hand.
