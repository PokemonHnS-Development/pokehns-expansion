## 1. Ground rules and prerequisites

### Do first
- **Flags and vars: done (2.0 part 1).** 2.0 has its own storage in SaveBlock3: **1,024 event flags** (0x2000–0x23FF) and **128 event vars** (0x7080–0x70FF), split into one block per build phase in `include/constants/hoenn_events.h`, plus **64 daily** and **64 weekly** flags of Hoenn & Seek's own (HnS's daily range is left alone). - **ROM:** ~1,009 KB free in the release build after part 1. Everything in this plan is estimated at ~440–720 KB, so it fits.
- **Trainer IDs:** 257 used (cap 912). Event battles are mostly scripted wild battles, so they don't use trainer IDs. New trainers (the abandoned Charmander's old trainer, etc.) do.
- **Phone:** the 36 free normal rematch slots are full. New phone trainers need a new flag scheme; event calls don't.

### Standing rules from 1.0 (apply to everything below)
- **Phone rule:** every new quest, area or battle gets a Brendan/May contact line or an event call, and every line says who told the caller.
- **Data-driven:** put new content in `data/hoenn/` JSON plus a generator in `tools/hoenn/` where it fits (hint table, event lists).
- **Overworld Pokémon:** they're generated into `map.json` by `tools/hoenn/gen_hoenn_ow_mons.py`. Re-run it after adding event objects or changing wild tables.
- **Touch upstream HnS files as little as possible:** new code in `hoenn`-named files; small hooks in shared files.
- **Untested items** go to `playtest-checklist.md`.
- **No Megas** (1.0 decision).

## 2. Core systems

### 2a. Weekdays and changing the time — Decided
**The problem:** HnS never asks for the weekday. The game's week starts on the RTC epoch's Saturday (`src/datetime.c`) and counts from when the clock was set, so its "Monday" usually isn't the real Monday. HnS also simplified HGSS's weekday content:
- Monica and the other siblings ask *you* what day it is (`multichoice MULTI_DAYS_OF_WEEK`); only the right answer works.
- The Union Cave Lapras appears once and resets after each Hall of Fame. It isn't weekly.
- Mt. Moon's Clefairy are there every night (night-only objects), not just Mondays. The white rock summons Jirachi at night.
- Only the PokéGear radio reads the weekday.

**The fix:**
- **A weekday offset (0–6) in the save** (a phase A event var). `GetDayOfWeek()` returns `(internal weekday + offset) % 7`. Don't shift the day counter itself: that would trigger daily resets and berry growth.
- **Set it everywhere the time can be set:**

  | Place | Today | Add |
  |---|---|---|
  | Title screen, **B + Select + Left** → reset-clock screen (`src/reset_rtc_screen.c`) | Days, hours, minutes | **Dropped in part 3** (Bryan, Nov 26): the screen only opens after a Mystery Event enables it (`CanResetRTC`, as in Emerald), so players never see it. It now records the week without a weekly reset, like HnS does for the daily one |
  | New game (`src/new_game.c` → `RtcReset()`) | Starts silently | A **"What day is it?"** prompt after the time, like HGSS (done in part 3, in New Bark's clock scene) |
  | Start menu clock (`src/start_menu.c`, `ShowTimeWindow`) | Shows the time | **Show the weekday** ("MON 3:45 PM") |
  | Debug menu → Time → "Set weekday…" (`src/debug.c`, fake RTC) | Debug builds only | Set the same offset (done in part 2: Utilities → "H&S time & weather…") |
  | **Wall clock in your room, New Bark** (decided) | **Already there** (found in part 2): a new game walks you to the clock (`NewBarkTown_PlayersHouse_2F_Script_ClockSetupTrigger1/2` → `StartWallClock`, which sets `FLAG_SYS_CLOCK_SET`), and the clock on the wall runs Emerald's wall-clock script | Add a weekday step to that scene and the wall clock (done, part 3) |
  | **Wall clock in every Pokémon Center** (found in part 3) | HnS lets you change the time at any Pokémon Center's wall clock (R in the clock view); 33 wall clocks share one script | The same "Change the day?" step (done, part 3) |

- **Wire HGSS's weekday content to it:**
  - The siblings check the day instead of asking.
  - Mt. Moon's Clefairy dance happens on **Monday nights**.
  - The Union Cave Lapras returns **every Friday**.
  - Check for other HnS honor-system prompts.
- **Weekly flags** reset at the start of each in-game week (`HoennClearWeeklyFlags`, part 1).
- **Built in part 2:** the offset (`VAR_HOENN_WEEKDAY_OFFSET`), `HoennSetWeekday()` for part 3's screens to call, and the weekly reset. Decided there: **the week starts on Sunday**; **changing the weekday is never a new week** (only days passing are), so fiddling with the day can't reset weekly events; setting the clock back and forward again does reset them, the same as HnS's daily flags.
- **Found in part 2:** the game's day 0 is a Saturday. A real save's day 0 is the day the wall clock was set, so its weekday is arbitrary until part 3 asks; a save that never set the clock (debug saves) uses the raw RTC day count, which starts at 1 on 1 Jan 2000, so it runs one day ahead of the real date. The offset fixes both.
- **A tip NPC** (2c) explains how to change the time and day.
- **Done in part 3** (PR #29). The day is asked at the start and offered at every wall clock; the start-menu clock shows it. Notes: `CLAUDE.md` → "Weekday content".

### 2b. Level caps past badge 8 — Decided
**Now** (`src/caps.c`): Johto badges 1–8 use a table (Normal 16, 21, 25, 31, 36, 38, 45, 56). After 8 badges it stays 56 until Johto champion, then 70 until Kanto champion, then no cap.

**New (Normal):**
| Progress | Cap | Based on |
|---|---|---|
| 8 Johto badges | 56 | Lance 56 (unchanged) |
| Johto champion, 0 Kanto badges | 60 | Lt. Surge (ace 60) |
| 1 / 2 / 3 / 4 / 5 / 6 / 7 Kanto badges | 62 / 63 / 64 / 66 / 66 / 67 / 69 | Erika 62, Misty 63, Janine 64, Brock 66, Sabrina 66, Blaine 67, Blue 69 |
| 8 Kanto badges (Kanto E4 rematch) | 70 | E4 68–69, Lance 70 |
| Kanto champion, 0 Hoenn badges | 70 | Never lower the cap |
| 1–7 Hoenn badges | 71, 72, 73, 74, 75, 77, 78 | The next leader's ace (gyms scale 68 → 78), at least 70 + badges. Part 4a: the planned +1 each (… 76, 77) fell below the 7th and 8th leaders' aces (77, 78) |
| 8 Hoenn badges (Hoenn E4) | 84 | E4 76–81, Wallace 80–84 |
| Hoenn champion (beat Wallace) | No cap | Brendan & May, Red, etc. |

- **Kanto gyms can be done in any order**, so the cap uses *how many* Kanto badges you have, stepping through the leaders' ace levels from lowest to highest.
- **Hard mode:** the same table minus ~2.
- **Hoenn badges** are counted from `FLAG_HOENN_STAMP_GYM_1..8`, separately from badges 1–16.
- **Done in part 4a** (`src/hoenn_caps.c`, a small hook in `caps.c`). The cap is the highest of every stage reached, so doing Hoenn before the Kanto E4 rematch can't lower it. Hard is −2 on every new row. Nothing after Wallace is capped: Mt. Silver and the Sinjoh post-game (rematch teams up to Lv 79) open only after Brendan & May.

### 2c. Smarter NPCs: alternating hint lines — Done (part 7)
- **Existing lines stay.** Selected NPCs alternate: first talk gives their current line, the next gives one extra line, then back.
- **Three kinds of extra line, each updating with progress:**

  | Kind | Examples | Changes when |
  |---|---|---|
  | **Tip** | How to change the time and day; where the Move Reminder, Name Rater or mind reader is; how level caps work | Rarely; some tips swap once they stop mattering |
  | **Rumor** | A nearby hidden event or a legendary clue ("Something white stands on the Route 120 cliff on stormy nights…") | The event is **seen**, or the legendary is **met** or **caught** ("Someone met the white one on the cliff!") |
  | **Story** | Where to go next ("The Mossdeep twins are waiting for someone with a meteorite…") | Badge count, quest stages |

- **How:**
  - **One global toggle var** flips on each talk, so there are no per-NPC flags.
  - **One table** (JSON → generated C) of `{id, kind, condition (flag / var / badge count), text before, text after}`.
  - **One special** (`special NpcHintLine` with the NPC's id). Each NPC script adds one `call`.
  - **Rumors reuse the flags** events and legendary chains already set.
  - **Each content part adds its own rumor/story lines** to the table (roadmap rule).
- **The field-notes researcher** (a Birch aide in Littleroot or a researcher in Fortree) summarizes: "You've found 12 of the 40 rumors," and gives the next vague hint.
- **Cost:** ~30–50 KB for 100 NPCs.
- **As built (part 7):** `data/hoenn/npc_hints.json` (lines, rumors, NPCs, forecasts) → `tools/hoenn/gen_hoenn_hints.py`; code in `src/hoenn_hints.c`. Instead of `special NpcHintLine`, each NPC's object runs a generated wrapper (`callnative HoennSeek_NpcHint`) that falls back to its own script, so upstream scripts aren't edited. Conditions: flags, vars, Hoenn badges, HnS badges, caught/not caught, level cap on. Rumor "seen/met" uses whatever flag the event sets (the first four use caught flags). The researcher is Birch's lab aide; ~6 KB for 23 NPCs.

### 2d. Trainers with follower Pokémon — Done (part 4b, stationary trainers only)
- **Hand-placed:** an object next to the trainer using the lead Pokémon's overworld sprite, like HnS's Mt. Moon Clefairy. ~24 bytes each, no code.
- **As built (part 4b):** `data/hoenn/trainer_followers.json` lists trainer (graphics_id) and species; `tools/hoenn/gen_hoenn_followers.py` picks the tile (rules in its header) and appends the objects. 30 followers: every gym leader in the three regions, both Elite Fours and Red (both summit maps), each with the ace of their first team (highest level; ties go to the signature Pokémon).
  - **Not hidden on defeat:** every leader here can be rematched, so the follower stays. It shares the trainer's flag instead, so it hides whenever the trainer does (Falkner's away flag, Winona before she's back, Red after his battle: `removeobject LOCALID_MTSILVER_RED_PIKACHU`, one line in HnS's summit script).
  - **Skipped:** Chuck (between his two rocks), Blaine (a rock niche), Tate & Liza (their dais's only open tiles are where you stand to talk), Janine (Fuchsia's trick is that every trainer looks like her), Lance and Wallace (walk-in champion scenes). Kanto's E4 rematch uses the Johto rooms and people, so it's covered.
  - **Palettes:** each follower adds at most one sprite palette. The busiest screen (Cerulean Gym) still has 3 of 16 slots free; checked in memory on all 30 screens, with and without the player's own follower.
- **Stationary and spin-in-place trainers only;** walkers are skipped.
- **Limits:** about 16 objects on screen, and each species' overworld sprite needs its own palette slot. **A few per screen at most** (gym leaders, aces, notable trainers).
- **Later option:** automatic spawning from party slot 1 (~100–200 lines of C).

### 2e. How weather works (reference, checked in source)
Weather is **not** random everywhere. Each map has a fixed weather in its header; some maps change it in zones or by day:
- **Hoenn (Emerald maps):**
  - **Fixed:** most routes are sunny. Mt. Chimney has ash, the Mt. Pyre summit fog, Petalburg Woods shade, and underwater maps bubbles.
  - **Zones:** walking into parts of a map changes the weather: Route 113's ash fields, Jagged Pass's ash, Route 120's rainy stretches, and Route 111's desert sandstorm (set by script on entry).
  - **Daily cycle:** **Routes 119 and 123** step through a 4-day cycle that advances once a day (`gSaveBlock1Ptr->weatherCycleStage`): Route 119 goes sunny → rain → **thunderstorm** → rain; Route 123 goes sunny → sunny → rain → sunny.
  - 1.0 turned off Emerald's abnormal (Kyogre/Groudon) weather.
- **Johto/Kanto (HnS maps):** mostly **no weather**. The exceptions are fixed:
  - always raining: Olivine City and its port, Cianwood City, Route 17
  - thunderstorms: Route 41 and the Lake of Rage
  - snow: Mt. Silver's snowy areas, Sinjoh Ruins and New Sinjoh
  - falling leaves: Bellchime Trail
  - sunny: the Tin Tower roof (day)
- **Scripts can set weather** for a scene (`setweather` + `doweather`), so an event can make it rain or storm while it runs. The Charmander event and the legendary chains use this.

### 2f. Daily weather cycles on most routes — Done (part 5; forecasts part 7)
- **Every route where weather makes sense gets a daily cycle**, like Route 119's. **Special weather 1 day in 4**, normal weather the other 3.
- **How:** a few generic cycle weather types (rain, thunderstorm, snow, fog, sandstorm), each a 4-day pattern with one special day, read from the same daily stage counter Emerald uses (`weatherCycleStage`). **Stagger them with offsets** so the whole map doesn't storm on the same day. ~30–50 lines plus map header changes.
- **Suggested assignments (adjust in the JSON):**

  | Region | Routes | Special day |
  |---|---|---|
  | Johto | Coastal and lake routes (29–34, 40–41, 43, Lake of Rage) | Rain or thunderstorm |
  | Johto | Mountain routes (44–46, Mt. Silver's outside) | Snow (Mt. Silver) / fog |
  | Kanto | Coastal and sea routes (12–13, 19–21, 24–25) | Rain |
  | Kanto | Route 10 (Power Plant) | **Thunderstorm**: the Zapdos feather day |
  | Kanto | Route 19–20 (Seafoam waters) | Fog or snow |
  | Hoenn | Routes 104, 114–118, 120–121, sea routes 124–134 | Rain / thunderstorm (Route 120 = **Absol's storm day**) |
  | Hoenn | Route 111's desert, Route 113 | Keep their sandstorm / ash zones; optionally a stronger sandstorm day |
- **Keep Route 119 and 123 as in Emerald** (119 is famously rainy: 3 of 4 days).
- **As built (part 5):** the table is `data/hoenn/weather_cycles.json` (78 routes, 27 groups; the file says what's left out and why). A map is special on the day `(weatherCycleStage + offset) % 4 == 2`; that day it **starts** in its special weather and its weather zones are skipped, the other three days it keeps its header weather (Johto/Kanto: none; Hoenn: sunny). No new weather types were needed: a generic "cycle type" is just the special weather plus an offset. Overworld weather carries into battle as in Emerald (rain on a rain day).
  - Changes from the suggestions above: Johto 35–39 and 42, Kanto's inland routes (1–9, 11, 14–16, 18, 22) and Hoenn 101–110 and 122 also cycle ("every route where weather makes sense"); Routes 40/41, the Lake of Rage and Route 17 stay permanent; Route 19–20 got fog; no sandstorm day for Route 111 (its sandstorm is already permanent in the desert).
- **Rainy places stay rainy (decided):** Olivine (and its port), Cianwood and Route 17 keep their permanent rain, as do Route 41's and the Lake of Rage's storms and the snowy areas.
- **Weather-gated steps use the cycle:** Absol's storm day, Zapdos's feather, Kyogre's rain and Groudon's heat wave (drought) all key off "today's special weather" on their route, instead of each scene forcing it.
- **Weather forecast (decided): only when it matters.** The PokéGear radio (Johto/Kanto) or the TV / Weather Institute (Hoenn) forecasts a route's special weather **only if something depends on it that day**: an event step that's still open (Absol not yet caught, a bird's feather not found, Kyogre/Groudon's cave), or a rare weather-only spawn (Castform and other weather-exclusive Pokémon, section 2g). No forecast on ordinary rainy days.
  - Example: "Storms are rolling in around Route 120 tonight. Folks say that's when the white one walks." Once Absol is caught, that forecast line stops.
  - Built on the hint-table idea (2c): each forecast entry is `{route, weather, condition flag, text}`.
  - **As built (part 7):** entries are `{map, if, text}` in `npc_hints.json`; the weather is the map's own special weather, and a forecast covers today and tomorrow ({STR_VAR_1}). Shown on **every TV** (in the player's region, before the normal show) and by the Weather Institute 1F worker. Johto/Kanto have no entries yet (nothing rare depends on their weather until Zapdos's feather), so the PokéGear radio isn't hooked; add it when they get one.

### 2g. Encounter tables by weather — Done (parts 6a, 6b)
- **What it does:** on a special-weather day, a route uses a **weather table** instead of its normal one. Mostly the **same species with shifted odds** (some more likely, some less), plus a few weather-only Pokémon:
  - **Rain:** Water and Bug types up (Lotad, Surskit, Marill, Poliwag), Fire types down.
  - **Thunderstorm:** Electric types up (Electrike, Mareep, Pikachu, Plusle/Minun), Flying types down.
  - **Snow:** Ice types appear (Snorunt, Swinub, Spheal).
  - **Sandstorm:** Ground/Rock up (Trapinch, Cacnea, Sandshrew, Baltoy).
  - **Fog:** Ghost types up (Shuppet, Duskull, Gastly, Misdreavus).
- **Castform (decided):** a **special-weather-only** wild encounter on Hoenn routes near the Weather Institute (119, 120, 123) and on the cycle routes, rare. Remove its Fuchsia Safari Brush slot (and the Safari Brush overworld Castform). The Weather Institute gift stays (1.0).
- It makes the cycle matter and gives a reason to come back on a stormy day.
- **What exists:** HnS's wild encounters already switch tables by **time of day** (`GetTimeOfDayForEncounters` in `src/wild_encounter.c`, with `_Day`/`_Night` tables). Nothing switches by weather yet; the only weather link is Sand Veil / Snow Cloak lowering encounter rates in their weather.
- **How:** add weather variants (`_Rain`, `_Storm`, `_Snow`, `_Sand`, `_Fog`) to the wild-table JSON and generator. In the lookup, if today's weather is special and the map has a matching table, use it; otherwise fall back to day/night as now. Weather beats time of day (optionally a `_RainNight` table where it matters). ~40–80 lines plus generator support. **Generate most tables by type rule, then review them by hand** (roadmap).
- **Cost:** ~100–200 bytes per table; ~10–20 KB for 60–100 tables.
- **Overworld Pokémon:** the generated decorative Pokémon follow day/night tables today; either leave them weather-blind or add weather swaps later.
- **Living dex:** weather-only Pokémon are fine, since 1 day in 4 comes around quickly. Avoid making a species weather-only *and* night-only on a route with a rare special day.
- **Data:** weather tables live with the other wild tables in `data/hoenn/` JSON (Hoenn) and the HnS wild JSON (Johto/Kanto); the generator emits the variants.
- **As built (part 6a):** `data/hoenn/weather_wild.json` holds the type rules, the weather-only extras and per-map fixes; `tools/hoenn/gen_hoenn_weather_wild.py` writes `data/hoenn/wild_encounters_weather.json` and the review list `hoenn-docs/weather-tables.md` (every route's shares before → after). The extras are evolved to the slot's level, so at Hoenn's Lv 35+ bands rain brings Lombre and Masquerain rather than Lotad and Surskit, storm brings Manectric and Plusle/Minun (Lanturn on water). Sandstorm has no cycle route yet, so it has no rule. Part 6b: Johto/Kanto use native extras (no Hoenn species, per section 10, and no Castform) and a living dex check in the generator. Weather beats time of day: each time-of-day table gets its own weather copy. Overworld Pokémon stay weather-blind.

### 3b. Hoenn's legendary sites become secret base locations — Decided
- **Done in part 12 (PR #41), with these changes from the plan (picked without Bryan, for review):**

  - The two chamber-bases (Sky Pillar summit, Sealed Chamber) were split off as **part 12b**.
- **Chamber-bases done in part 12b (PR #42), picked without Bryan (review):** groups 24 and 25 (IDs 241 and 251) with their own interiors. The chamber rooms themselves aren't decorated (puzzles, braille, no decoration-friendly floor): a Secret Power spot in each (Sky Pillar summit back wall, Sealed Chamber inner top wall) leads to a themed base, a recolour of an Emerald cave base's tiles in the site's colours (Sky Pillar: Yellow Cave 4's shape, lavender-grey stone floor and tan walls like the tower; Sealed Chamber: Brown Cave 4's shape, sand floor and dark brown stone). To change the art, edit `data/hoenn/base_spots.json` (`chambers`) and re-run `tools/hoenn/gen_hoenn_base_spots.py`.
  - Phone: May calls once your base is at one of the sites (an aide charting them for the League told her); two Pokémon Center NPCs mention the reopened sites.
- **Legendaries stay where HnS puts them** (section 4). The sites reopen without them.
- **Steps:** revert part 12's sealing commit (CLAUDE.md says how; the clone needs enough history to reach commit `23adc4fc`); remove the legendary objects and encounters, keeping each site's puzzles (braille, ice, ledges) and items; add a secret base spot at the end of each dungeon.
- **Two showpiece chamber-bases:** **Sky Pillar summit** and the **Sealed Chamber** become decoratable bases themselves. Base IDs are `u8` (group × 10 + variant); 24 groups use IDs up to 233, so **exactly two groups are free** (24 and 25, IDs 240–255; checked). Each needs its layout's floor tiles set for decorations.
